# Streakline

A focused, offline-first single-habit tracker built with plain HTML, CSS and JavaScript.

## Features
- Daily calendar check-ins
- Current and best streak tracking
- Weekly target and consistency metrics
- Day notes (double-click, right-click, or long-press a date)
- Achievements and 12-month insights
- Habit name/icon customization
- JSON export/import backups
- Local-only storage with no account required
- Installable PWA support when served over HTTP(S)
- Responsive, keyboard-friendly UI

## Run
Open `index.html` directly, or serve the folder for full PWA/service-worker support:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
