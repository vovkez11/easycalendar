# 📅 Habit Tracker Calendar

A simple, efficient calendar app to track daily habits with local storage persistence.

## Features
- ✅ Click to mark days as completed
- ✅ Automatic data saving (localStorage)
- ✅ Month navigation
- ✅ Total completion counter
- ✅ Clean, modern design
- ✅ Mobile responsive

## Usage
1. Open `index.html` in any browser
2. Click on any day to toggle completion status
3. Your progress persists automatically

## Running Locally
Just open the `index.html` file - no build process needed!

## Technologies
- Vanilla JavaScript
- CSS3 Grid
- LocalStorage API
